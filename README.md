# Django Student Registration System

## Overview
A simple Student Registration System developed using Django.

## Features
- Student Registration Form
- Stores student details in SQLite Database
- Django Admin Panel
- View Registered Students

## Technologies Used
- Python
- Django
- HTML
- SQLite

## How to Run

```bash
python manage.py runserver
```

Open:

http://127.0.0.1:8000/
